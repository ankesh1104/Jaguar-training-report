Gmail Setup (direct send — free)

One-time setup so the app can send mail directly from your own Gmail account with one click (no third-party service, no branding). Takes ~10 minutes, free.
  1. Go to console.cloud.google.com, create a project (or use an existing one).
  2. APIs & Services → Library → search "Gmail API" → Enable.
  3. APIs & Services → OAuth consent screen → set it to External, fill the required fields, and under Test users add your own Gmail address.
  4. APIs & Services → Credentials → Create Credentials → OAuth client ID → Application type: Web application. Under Authorized JavaScript origins, add your exact live site URL (e.g. https://your-site.netlify.app).
  5. Copy the Client ID it gives you (looks like 123...apps.googleusercontent.com) and paste it below.
The first time you click send, Google will show a one-time consent popup since this is your own personal app — click "Continue"/"Advanced → Go to (app name)" to proceed. This value is not secret and is stored only in your browser.

Google Sheet Log Setup

One-time setup so every report also logs a row in your own Google Sheet. Free, ~3 minutes.
  1. Create a new Google Sheet (or use an existing one). In row 1, add these headers across columns A–N:
    Timestamp | Client | Site | Date | Contact Person | Mode | Trainer | Designation | Topic | Category | Attendees | Objectives | Outcomes | Recipient
  2. In the Sheet, go to Extensions → Apps Script. Delete any existing code and paste this (if you already set this up before, replace your old code with this updated version — it adds the ability to read data back for the Dashboard):
    function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); sheet.appendRow([ new Date(), data.clientName, data.siteName, data.trainingDate, data.contactPerson, data.trainingMode, data.trainerName, data.designation, data.trainingTopic, data.topicCategory, data.totalAttendees, data.objectives, data.outcomes, data.recipientEmail ]); return ContentService.createTextOutput(JSON.stringify({status:'success'})) .setMimeType(ContentService.MimeType.JSON); } function doGet(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var values = sheet.getDataRange().getValues(); var rows = values.slice(1); // skip header row var out = rows .filter(function(r){ return r[1] || r[2]; }) // skip fully blank rows .map(function(r){ return { timestamp: r[0], client: r[1], site: r[2], date: r[3], contactPerson: r[4], mode: r[5], trainer: r[6], designation: r[7], topic: r[8], category: r[9], attendees: r[10], objectives: r[11], outcomes: r[12], recipient: r[13] }; }); return ContentService.createTextOutput(JSON.stringify(out)) .setMimeType(ContentService.MimeType.JSON); }
  3. If this is a first-time setup: click Deploy → New deployment → gear icon → select Web app. Set "Execute as" = Me, "Who has access" = Anyone. Click Deploy, and authorize when asked.
    If you're updating an existing setup: click Deploy → Manage deployments → pencil (edit) icon → Version: New version → Deploy. This keeps your existing URL working.
  4. Copy the Web app URL it gives you and paste it below.
